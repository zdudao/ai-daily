# 打赏功能需求文档

> 项目：老许聊实体 · AI×实体洞察日报（https://zdudao.github.io/aikaifeng/）
> 文档目的：明确「网页（PC）增加打赏」与「手机页面增加打赏」的功能需求，作为开发与验收依据。
> 状态：**已实现**（本文件仅记录需求，不涉及代码改动）

---

## 1. 需求背景

日报每天自动抓取几百条 AI 资讯、逐条研判、写成"开封话"决策建议，背后是实打实的**人工投入与 LLM 算力成本**。

为让日报能长期持续更新，需要为读者提供一个**打赏赞助入口**，表达对内容价值的认可，并分担维护成本。

打赏是日报的**第二目的**（第一目的是阅读新闻），因此入口要"被看见、易操作"，但不干扰阅读。

---

## 2. 总体目标

| 目标 | 说明 |
|------|------|
| 全站可见 | 首页与所有历史日报页都有打赏入口 |
| 双端适配 | PC 与手机端各有合适的打赏形态 |
| 不干扰阅读 | 入口存在但不遮挡正文、不影响新闻浏览 |
| 二维码清晰 | 打赏二维码足够大、可被正常扫码 |

打赏卡片统一文案：

> **☕ 请老许喝碗胡辣汤**
> 这份日报每天抓取几百条 AI 资讯、逐条研判、写成开封话讲给你听，背后是实打实的人工和算力成本。觉得有用，扫码支持一下，让日报能一直做下去。
> 微信 / 支付宝 扫码打赏

## 3. PC 端（网页）打赏需求

### 3.1 形态：右侧独立打赏列

- 页面改为**三列布局**：左侧导航栏 | 中间日报内容 | **右侧打赏列**
- 右侧打赏列特征：
  - 独立一列，宽度约 260px，页面最大宽度 1400px
  - **sticky 固定**：滚动阅读时打赏列始终停靠在右侧，随时可扫码
  - 深色卡片样式（背景 `#1a1a1a`、黄绿色描边、圆角），与整体深色科技风一致
- 二维码要求：**200×200px**，居中、白底、不超边框、清晰可扫

### 3.2 覆盖范围

- 首页 `index.html`
- 所有历史日报页 `news-data/daily-*.html`
- 每天 13:00 自动生成的日报自动带上该入口

### 3.3 卡片内容

- 标题：☕ 请老许喝碗胡辣汤（黄绿色，约 16px）
- 说明文字（约 13.5px）
- 收款二维码（200×200px）
- 提示：微信 / 支付宝 扫码打赏

### 3.4 验收标准（PC）

- [ ] 三列布局正常，无横向滚动
- [ ] 打赏列滚动时保持固定可见（sticky 生效）
- [ ] 二维码 200px、居中、不超边框
- [ ] 首页与所有历史日报页都有该入口
- [ ] 无 JS 报错

## 4. 手机页面打赏需求

### 4.1 形态：右下角浮动按钮 + 二维码弹窗

手机屏幕小，放不下右侧列，打赏必须"一直可见"且"点击即得"，因此采用**浮动按钮 + 弹窗**：

- **浮动按钮**：
  - 页面加载即显示，**无需打开任何菜单**
  - 固定在**右下角**（距右约 14px、距底约 18px），滚动时不消失
  - 黄绿色渐变圆形胶囊按钮，文字"☕ 打赏"，醒目但小巧（约 87×43px）
  - 不遮挡新闻卡片与正文链接
- **二维码弹窗**：
  - 点击浮动按钮弹出
  - 全屏半透明遮罩 + 深色卡片（约 320px 宽）
  - 内容：标题、说明、**200×200px 二维码**、提示
  - 关闭方式：右上角 ✕ 按钮 或 点击遮罩空白处

### 4.2 与导航菜单的关系

- 打赏入口**不藏在 ☰ 导航菜单里**（此前版本曾放菜单中，不符合"被看见"要求，已移除）
- 导航菜单只保留：分类、行动分级、历史日报

### 4.3 移动端整体体验（不影响打赏）

- 顶栏收成细条（约 44px）：品牌 + ☰ 按钮，正文占大部分屏幕
- ☰ 展开全屏导航菜单，点导航项后自动收起

### 4.4 验收标准（手机）

- [ ] 页面加载即见右下角"☕ 打赏"浮动按钮
- [ ] 滚动页面按钮一直可见
- [ ] 点击弹出二维码弹窗（200px 大码，清晰可扫）
- [ ] ✕ / 点遮罩可关闭弹窗
- [ ] 打赏入口不在 ☰ 菜单中
- [ ] 浮动按钮不遮挡正文、不影响卡片点击
- [ ] 无 JS 报错

## 5. 双端差异对照

| 项 | PC 端 | 手机端 |
|----|-------|--------|
| 入口位置 | 右侧独立打赏列（sticky） | 右下角浮动按钮 |
| 二维码大小 | 200×200px | 弹窗内 200×200px |
| 是否常驻 | 是（滚动时固定） | 是（浮动按钮常驻） |
| 扫码方式 | 直接扫右侧二维码 | 点按钮 → 弹窗 → 扫码 |
| 是否进菜单 | 否 | 否 |

---

## 6. 打赏二维码素材

- 收款码图片：仓库根目录 `donate.png`（640×640 方形 PNG，白底居中）
- 原图备份：`shou.jpg` / `shou.png`（本地，不入库）
- 所有页面（首页/日报页）通过相对路径引用：首页 `donate.png`，日报页 `../donate.png`

---

## 7. 实现备注（供开发参考，非需求）

- 打赏入口由 `scripts/build_index.py` 统一注入（`inject_donate`），每次生成日报/首页时自动带上
- PC 端：`aside.donate-panel` 注入 `</main>` 之后
- 手机端：`button.donate-fab` + `div.donate-modal` 注入 `</body>` 前
- 显隐由 CSS 断点控制：`min-width:1101px` 显示右侧列 / `max-width:860px` 显示浮动按钮
- 二维码图片路径按页面目录区分前缀（index 空、日报 `../`）
