# AI 新闻分类（实体商业视角）

对下面的每条新闻，从以下 8 个类别中选出**最贴切的一个主分类**（单选），并给一句话分类理由。分类要服务于"实体老板找自己关心的内容"这个目的——视频生成就是视频生成，别把"Seedance 降价"归到"大模型"。

## 类别定义

1. **视频生成**：AI 视频生成 / 剪辑 / 数字人 / 口播（如 Seedance、剪映、LibTV、HeyGen 视频、Runway）
2. **图像生成**：AI 生图 / 商品图 / 图片编辑 / 设计（如 Grok Imagine、Qwen-Image、Lovart、即梦生图、美图）
3. **智能体与自动化**：AI 同事 / 数字员工 / Agent / 工作流自动化 / 机器人（如 Grok Bot、CatPaw、WorkBuddy、Manus）
4. **文本与内容**：文案写作 / 对话问答 / PPT / 知识整理 / 翻译（如 ChatGPT、AI帮写、Kimi、豆包对话）
5. **大模型与API**：模型发布 / 开源 / API 降价 / 云平台底层能力（如 DeepSeek、Amazon Bedrock、Qwen 模型、token 价格）
6. **平台与商业模式**：大厂产品动态 / 收费模式 / 广告 / 流量入口 / 电商平台（如抖音、微信、美团、OpenAI 广告、大厂开战）
7. **政策与宏观**：政府政策 / 行业报告 / 投融资动态
8. **其他**：不属于以上任何类别
